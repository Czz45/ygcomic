# YGComic

一个把「本地收藏」和「在线书源」装进同一个书架的安卓阅读器。漫画、小说一站式阅读，界面采用 MIUI / HyperOS（Miuix）设计语言，并为骁龙平台准备了 AI 超分能力。

当前版本：**v0.1.212**（持续迭代中）

---

## 项目定位

做一个真正好用、可扩展的移动端阅读器：

- **一个书架装下所有内容**：本地漫画、TXT 小说、PDF，以及来自在线书源的作品，统一管理。
- **两种阅读体验各司其职**：漫画阅读器专注图片分镜与手势，小说阅读器专注排版与朗读。
- **紧跟系统观感**：基于小米 Miuix 组件库，贴近澎湃 OS 的原生质感与动效。
- **为画质留好天花板**：内置超分引擎，让老图、低清图在大屏上也能更好看。

---

## 路线图

- **阅读体验持续打磨**：封面展开、文件夹飞入等共享元素动画，顺滑的页面转场与手势交互。
- **听书能力升级**：多套 TTS 配置、自定义试听、音色/语速/情绪可调，并预留本地大模型朗读。
- **画质增强**：ncnn + Real-CUGAN 超分，走 Vulkan GPU，结果落盘缓存，按原尺寸处理。
- **书源生态**：Legado、异次元、Mihon 三套体系各自独立、可切换、可单独开关。
- **内容拓展**：番剧 / 动漫能力调研与接入（评估 Kazumi、Animeko 等开源方案）。
- **更多平台**：Windows 端与 Rust 底层引擎的可替换架构已预留边界。

## 已实现

### 书架与导入
- SAF 批量导入 zip / 7z / rar / PDF / 图片文件夹 / TXT，自动拆分与手动合并
- 树形合集管理，重命名、删除、归类，密码存入 Android Keystore
- 筛选、排序、进度显示，封面与卡片随内容自然排布
- PDF 实时读取（秒级导入、按需渲染），TXT 直读引用不复制原文件

### 漫画阅读器
- LTR / RTL / 条漫三种模式，进度自动记忆，全屏沉浸
- 单击显隐控制栏、双页模式、缩放滑杆、自然排序的上一本/下一本
- 图片按原始宽高比完整显示，加载中不闪、已加载页稳定
- 两指捏合放大、目录弹窗、按书源记忆的正序/反序

### 小说阅读器
- 独立排版：字体、字号、行距、字距、段间距、边距、首行缩进、背景色
- 章节自动识别与目录跳转；TTS 朗读，支持系统 / 网络 / 本地大模型多套配置
- 音色、语速、情绪、风格可调，可粘贴文本试听

### 书源体系
- Legado / 异次元 / Mihon 三套源包独立管理，逐条开关
- 网络层对接 Cloudflare 处理、RSA/JS 解密、zstd 压缩等常见站点能力
- 搜索聚合、替换规则、源健康度评分

### 画质增强
- ncnn + Real-CUGAN 2x 超分，支持 Vulkan GPU 与 CPU 回退，精度锁 FP32
- 预渲染/预超分，结果落盘缓存，批量队列支持暂停/继续/停止与实时进度
- 全程保持原尺寸，封面进度块、彩虹光效、已超分标记等状态可视化

### 系统与体验
- MIUI / HyperOS（Miuix）风格主题，悬浮胶囊底栏、级联菜单、共享元素动画
- 内置版本检查与更新安装，走 GitHub Releases，兼容国内网络代理
- 手写 SQLite + 内存态数据层，新增类型无需改表结构
