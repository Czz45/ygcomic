# YGComic

YGComic 是一款 Android 漫画与小说阅读器。本地收藏和自己选的在线书源可以放进同一个书架，打开一本书就能接着上次的位置读。

## 特色功能

- **漫画预超分**：长按书架封面，把低清图片按原尺寸输入做 2× 超分。处理好的图片缓存在本机，阅读时直接使用，不用边翻页边计算。
- **适合长图的漫画阅读器**：支持纵向条漫、从左到右和从右到左翻页。长图按原宽高比铺开，也能双指放大看细节。
- **小说既能看，也能听**：一本书可以单独设字体、行距和背景；用系统语音或自己配置的网络语音朗读，支持倍速和定时关闭。
- **澎湃风格的书架与阅读器**：用 Miuix 做悬浮控制栏和封面展开转场，从封面点进去就是阅读页。

## 功能细节

### 本地导入与书架

- 书架支持批量导入 ZIP、7Z、RAR、图片文件夹、PDF 和 TXT，可用合集归类、筛选和排序。
- PDF 按需渲染，TXT 可以直接读取所选文件。漫画页码和小说阅读位置分别记录，下次打开继续读。
- 漫画超分支持查看批量进度、暂停、继续和停止；缓存保存在应用目录，不改原文件。

### 在线书源与换源

- 开源阅读（Legado）、异次元和 Mihon 分开管理，支持导入兼容的书源或扩展，来源可以单独启停。搜索和阅读效果取决于所用来源。
- 在线作品可以加入书架。小说换源时会尽量对齐当前章节和章内位置；目录支持正序、反序和按章号整理。
- 可从「设置 → 备份与迁移」导入「阅读」（Legado）的备份，迁移书架、书源、阅读进度和文本替换规则。

### 小说排版与朗读

- 可调字体、字号、字距、行距、边距和首行缩进，并按书保存排版设置。支持目录跳转和按卷显示。
- 朗读可从当前阅读位置开始，支持试听、暂停续听、通知栏控制。使用网络语音时，需自行配置相应服务。

### 番剧（试验功能）

公开测试版提供搜索、选集、续播和加入书架。需自行配置视频来源，能否播放取决于来源及其媒体格式。

## 下载与使用

1. 在 [GitHub Releases](https://github.com/Czz45/ygcomic/releases) 找到公开测试版，在该版本的 **Assets** 中下载 APK。
2. 看本地文件：打开书架，点右上角「＋」导入。看在线内容：先到书源管理添加自己的书源或扩展。

**公开 APK 不附带书源或内容。** 各版的设备要求、改动和已知限制以对应的发布说明为准。

## 技术细节

- 界面：Kotlin、Jetpack Compose 和 Miuix。书源规则由 Rust 引擎处理。
- 图像增强：ncnn + Real-CUGAN 2×，支持 Vulkan 的设备可走 GPU，也支持 CPU 回退。

项目仍在持续开发，当前重点是阅读体验、书源兼容和番剧播放。遇到问题可在 [Issues](https://github.com/Czz45/ygcomic/issues) 反馈，附上版本号、机型、操作步骤和报错；请勿附带账号、密钥或私密书源。
